# 🚀 Astro Shooter

A 2D space shooter developed independently using **Unity and C#**.

## 🎮 Play the Game

[Play Astro Shooter on itch.io](https://elbi-n.itch.io/astro-shooter)

## About the Game

Take control of a spaceship, destroy incoming asteroids, dodge debris, and survive as long as possible while aiming for your highest score.

## Features

- Player movement and laser shooting
- Random asteroid spawning
- Asteroid debris spawning
- Collision detection
- Score system
- Particle explosion effects
- Camera shake
- Main menu and game-over system

## Technologies Used

- Unity
- C#
- Git and GitHub

## Controls

| Key | Action |
|---|---|
| A / D | Move left and right |
| R | Restart after Game Over |

Created as an independent game development project while learning Unity and C#.
